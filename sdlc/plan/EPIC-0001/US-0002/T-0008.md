# T-0008: Escribir queries sqlc de canales en `scripts/sqlc/channel.sql` y generar código

## Descripción técnica:
Crear `scripts/sqlc/channel.sql` [NUEVO] con las queries: `ListChannels` (ORDER BY number), `GetChannelByID`, `CreateChannel`, `UpdateChannel`, `DeleteChannel`, `ExistsChannelNumber` (`SELECT EXISTS(...) WHERE number=$1 AND id<>$2`). Crear `sqlc.yaml` [NUEVO] en la raíz: schema desde `migrations/`, queries `scripts/sqlc/channel.sql`, salida Go en `internal/channel/` con paquete `channel`. Ejecutar `sqlc generate` y commitear los archivos generados (`queries.sql.go`, `models.go`, `db.go`). Los archivos generados no se testean directamente ni cuentan para coverage (llevan header `DO NOT EDIT`).

## Criterios de aceptación:
- [ ] `sqlc generate` produce código que compila contra el esquema de `migrations/`
- [ ] Los tipos generados mapean `sources` como `json.RawMessage`/JSONB

## Definición de finalizado (DoD):
- [ ] Tests unitarios de la lógica agregada/modificada en verde
- [ ] Tests existentes sin romper
- [ ] Lint/type-check sin errores (`go vet` y `gofmt` limpios)
- [ ] Código mergeado tras code review
- [ ] Deployable de forma independiente (sin pasos manuales fuera del pipeline)

## Proyecto / módulo: rodritv-api / `scripts/sqlc/channel.sql`, `sqlc.yaml`, `internal/channel/queries.sql.go`, `internal/channel/models.go` (generados)
