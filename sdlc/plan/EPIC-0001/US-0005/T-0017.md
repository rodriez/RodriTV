# T-0017: Crear `Service` y `Handler` de métricas y registrar la ruta

## Descripción técnica:
Crear `internal/metric/service.go` [NUEVO]: `NewService(repo Repository, channelSvc *channel.Service)` — `Get(ctx, channelID, window)` verifica primero que el canal existe (delegando en `channel.Service.Get`; si `ErrNotFound` se propaga → 404) y compone la respuesta incluyendo `slot` de las sources actuales del canal para el cruce con `source_slot`. Handler con parseo de query param `window`. Registrar `"GET /v1/channels/{id}/metrics"` en `routes.go` y cablear en `main.go`.

## Criterios de aceptación:
- [ ] Canal inexistente → 404 `not_found`
- [ ] Respuesta coincide con el contrato SPECS-001.5.4 (`channel_id`, `window`, `uptime`, `sources[]`, `interruptions`)
- [ ] Canal sin samples → `uptime: 0` y array `sources` con las sources actuales en `state: "standby"`/`active:false`
