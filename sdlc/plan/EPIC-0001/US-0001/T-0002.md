# T-0002: Crear pool pgx con retry en `internal/platform/db.go`

## Descripción técnica:
Crear el paquete `internal/platform` [NUEVO] con `db.go` [NUEVO]: función `NewPool(ctx context.Context, dsn string, log *slog.Logger) (*pgxpool.Pool, error)` sobre `github.com/jackc/pgx/v5/pgxpool` con `MinConns=2`, `MaxConns=10`. Antes de retornar, `Ping` con backoff exponencial (inicio 250 ms, ×2, tope 5 s) hasta un máximo de 30 s; agotado el tiempo devuelve error.

## Pseudo código:
```
cfg, _ = pgxpool.ParseConfig(dsn); cfg.MinConns=2; cfg.MaxConns=10
pool = pgxpool.NewWithConfig(ctx, cfg)
deadline = now + 30s; wait = 250ms
mientras now < deadline:
    si pool.Ping(ctx) == nil: retornar pool
    sleep(wait); wait = min(wait*2, 5s)
retornar error "db no disponible tras 30s"
```

## Criterios de aceptación:
- [ ] Dada una DB alcanzable, retorna pool funcional (`SELECT 1` ok)
- [ ] Dada una DB caída, retorna error tras ~30 s con reintentos (verificable con contenedor detenido)
