# T-0070: Crear `deployments/.env.example` sin secretos

## Descripción técnica:
Crear `deployments/.env.example` [NUEVO] con las variables que consume `docker-compose.yml` (T-0069), con valores de ejemplo y **sin secretos reales** (la contraseña la genera `install.sh`, T-0071): `TAG` (ej. `0.1.0`), `POSTGRES_USER=rodritv`, `POSTGRES_PASSWORD=` (vacía, con comentario indicando que la genera install.sh), `POSTGRES_DB=rodritv`, `TZ=America/Cordoba`. Cada variable con un comentario breve de su propósito.

## Criterios de aceptación:
- [ ] `cp deployments/.env.example deployments/.env` + completar `POSTGRES_PASSWORD` permite `docker compose config -q` sin errores
- [ ] El archivo no contiene ninguna credencial real (revisión manual)
- [ ] Cubre exactamente las variables referenciadas por `docker-compose.yml` (ni faltantes ni huérfanas)

## Definición de finalizado (DoD):
- [ ] Validación contra compose en verde
- [ ] Tests existentes sin romper
- [ ] Código mergeado tras code review
- [ ] Deployable de forma independiente (sin pasos manuales fuera del pipeline)
