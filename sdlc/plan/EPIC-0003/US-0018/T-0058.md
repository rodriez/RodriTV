# T-0058: Crear `layout.html`, `panel.css` (grid responsivo) y `panel.js`

## Descripción técnica:
Crear `web/templates/layout.html` [NUEVO]: esqueleto VSCode con `<header>` (nombre app + nav a Canales/Configuración/Monitoreo), `<aside id="sidebar">` (bloque `sidebar`), `<main id="main">` (bloque `content`), `<section id="bottom">` (bloque `bottom`, plegable). Incluye `<script src="/static/vendor/htmx.min.js" defer>`, `/static/js/panel.js` y `/static/css/panel.css`. Crear `web/static/css/panel.css` [NUEVO] (~300 líneas, variables CSS, mobile-first): grid desktop `260px 1fr` / fila bottom `220px`; < 768 px una columna con sidebar y bottom plegables (clase `.collapsed`); clases de estado `st-on/st-standby/st-off/st-unknown` (de `stateClass`, T-0057). Crear `web/static/js/panel.js` [NUEVO]: toggle de paneles (botones con `aria-expanded`), helper que marca el canal activo en la sidebar tras `htmx:afterSwap`, y listener `htmx:responseError` que inyecta el banner "API no disponible, reintentando" en el target.

## Pseudo código:
(panel.js)
```
document.addEventListener('click', e => si e.target es [data-toggle]: toggle .collapsed en el panel)
document.body.addEventListener('htmx:afterSwap', e => resaltar channelId activo en sidebar)
document.body.addEventListener('htmx:responseError', e => e.target.innerHTML = bannerError)
```

## Criterios de aceptación:
- [ ] El test de parseo de T-0057 sigue en verde con `layout.html` incluido
- [ ] En viewport ≥ 768 px se ven las 3 regiones; en < 768 px sidebar y bottom colapsan al tocar su cabecera (verificación manual + comentario en CSS del breakpoint)
- [ ] La página usa únicamente assets `/static/*` (sin CDN)
- [ ] `htmx:responseError` muestra el banner sin romper el resto del DOM
