# T-0059: Crear handlers de páginas de canales en `internal/panel/pages.go`

## Descripción técnica:
Crear `internal/panel/pages.go` [NUEVO] (paquete `panel`) con la struct `Handlers` (`api apiclient.APIClient`, `render Renderer`, `logger *slog.Logger`) y `NewHandlers(api, render, logger) Handlers` (struct, inyectada desde main). Handlers:
- `Home`: `GET /` → redirect 303 a `/channels`.
- `ChannelsPage`: `GET /channels` → llama `api.ListChannels(ctx)`; renderiza página completa `pages/channels.html` [NUEVO] (extiende `layout.html`) con sidebar = lista y main = detalle del primer canal (si existe); sin canales → estado vacío con botón "Nuevo canal".
- `ChannelPage`: `GET /channels/{id}` → igual pero con detalle del canal `{id}` (`api.GetChannel`); 404 de la API → redirect a `/channels` (el canal ya no existe); error de red → página con banner "API no disponible".
Registrar las 3 rutas en `cmd/web/routes.go`. Tests `internal/panel/pages_test.go` [NUEVO] con `httptest` y `APIClient` mockeado (`testify/mock`), verificando contenido con `strings.Contains`. `go mod tidy` para `github.com/stretchr/testify`.

## Pseudo código:
```
ChannelPage(w, r):
    id = r.PathValue("id")
    channels, err = api.ListChannels(ctx)
    si err red: render página con banner; return
    selected, err = api.GetChannel(ctx, id)
    si IsNotFound: redirect /channels; return
    render.Render(w, "channels.html", {Channels, Selected: selected})
```

## Criterios de aceptación:
- [ ] `GET /` responde 303 con `Location: /channels`
- [ ] Dado 2 canales mockeados, `GET /channels` contiene ambos nombres y el detalle del de menor `number`
- [ ] Dado `GetChannel` 404, `GET /channels/{id}` redirige a `/channels`
- [ ] Dado `ListChannels` con error de red, la página contiene "API no disponible" y status 200
- [ ] La página completa incluye sidebar, main y bottom (estructura del layout)
