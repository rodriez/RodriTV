# T-0061: Crear fragmento de alta de canal (POST /frag/channels)

## Descripción técnica:
Agregar a `internal/panel/fragments.go` [NUEVO] el handler `ChannelCreateFragment`: `POST /frag/channels` (`hx-post`, `application/x-www-form-urlencoded`). Parsear el form a un `apiclient.Channel` con el parser compartido `parseChannelForm(r) (Channel, error)` (nuevo en el mismo archivo; lo reutiliza T-0062): campos escalares + array de 5 slots leído de inputs `slot_url_1..5` y `slot_enabled_1..5` (slot con URL vacía → `nil`; con URL → `&Source{Slot: i, URL: u, Enabled: …}`). Validación mínima en servidor (nombre y número requeridos, `segment_seconds` 2–10) antes de llamar a la API; luego `api.CreateChannel`. Respuestas: éxito → fragmento lista actualizada + detalle del nuevo canal (out-of-band swap con `hx-swap-oob`) y header `HX-Trigger: channelsChanged`; 400 → re-render del formulario con `Fields` del `APIError` junto a cada input; 409 → error en campo `number` ("número duplicado"); red/5xx → banner "API no disponible". Template `partials/channel_form.html` [NUEVO] compartido alta/edición (valores + errores por campo). Registrar ruta en `cmd/web/routes.go`.

## Pseudo código:
```
ch, ferr = parseChannelForm(r)
si ferr: render channel_form con errores locales; return
created, err = api.CreateChannel(ctx, ch)
si IsValidation(err): render channel_form{Values: ch, Errors: err.Fields}; return
si IsConflict(err): render channel_form{Errors: {number: "número duplicado"}}; return
si err red: banner API no disponible; return
w.Header(HX-Trigger: channelsChanged)
render lista (oob) + channel_detail{created}
```

## Criterios de aceptación:
- [ ] Dado un form válido con sources en slots 1 y 3, el `Channel` enviado a la API tiene `Sources[0]` y `[2]` con `Slot` 1 y 3, y `nil` en el resto
- [ ] Dado 400 con `fields.name`, el fragmento re-renderiza el formulario mostrando ese mensaje junto al input nombre y status 200 (htmx swap normal)
- [ ] Dado 409, el mensaje de duplicado aparece junto al campo número
- [ ] Dado éxito, la respuesta incluye `HX-Trigger: channelsChanged` y la lista contiene el nuevo canal
- [ ] Dados nombre o número vacíos, no se llama a la API (error local inline)
