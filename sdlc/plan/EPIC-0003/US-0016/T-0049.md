# T-0049: Crear `Config` con Viper en `cmd/web/config.go`

## Descripción técnica:
Crear `cmd/web/config.go` [NUEVO] con la struct `Config` (`Port int`, `APIURL string`, `APITimeout time.Duration`, `LogLevel string`, `ShutdownTimeout time.Duration`) y `LoadConfig() (Config, error)`. Viper con `AutomaticEnv`, prefijo `RODRITV_WEB`, `BindEnv` explícito por clave y defaults según SPECS-003.6: `PORT=9292`, `API_URL=http://localhost:9291`, `API_TIMEOUT=10s`, `LOG_LEVEL=info`, `SHUTDOWN_TIMEOUT=10s`. `Validate()` falla si: puerto fuera de 1–65535, `APIURL` sin esquema http(s), `APITimeout` o `ShutdownTimeout` ≤ 0, `LogLevel` fuera de `debug|info|warn|error`. `go mod tidy` para agregar `github.com/spf13/viper`.

## Pseudo código:
```
v = viper.New(); v.SetEnvPrefix("RODRITV_WEB"); v.AutomaticEnv()
set defaults; bind env por clave
cfg = Config{Port, APIURL, APITimeout, LogLevel, ShutdownTimeout}
si err := cfg.Validate(); err != nil: retornar err (fail fast)
```

## Criterios de aceptación:
- [ ] Sin variables seteadas, `Port`=9292, `APIURL`=`http://localhost:9291`, `APITimeout`=10s, `ShutdownTimeout`=10s
- [ ] Dado `RODRITV_WEB_API_URL=api:9291` (sin esquema), `LoadConfig()` devuelve error de validación
- [ ] Dado `RODRITV_WEB_PORT=0` o `70000`, `LoadConfig()` devuelve error
- [ ] Dado `RODRITV_WEB_LOG_LEVEL=verbose`, `LoadConfig()` devuelve error indicando los valores válidos
