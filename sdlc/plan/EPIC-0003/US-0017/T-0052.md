# T-0052: Crear modelos espejo del contrato en `internal/apiclient/models.go`

## Descripción técnica:
Crear `internal/apiclient/models.go` [NUEVO] con los tipos espejo del contrato JSON de SPECS-001.5 (paquete `apiclient`), con `omitempty` en opcionales y tags JSON exactos:
- `Source` (`ID string`, `Slot int`, `URL string`, `Enabled bool`, `CreatedAt time.Time`, `UpdatedAt time.Time`)
- `Channel` (`ID`, `Number int`, `Name string`, `Logo string`, `ScheduleURL string`, `Enabled bool`, `SegmentSeconds int`, `Sources [5]*Source` — array fijo de 5 punteros, nil = slot vacío — `CreatedAt`, `UpdatedAt`)
- `Config` (`Neighbors int`, `StartupChannels int`, `CurrentChannelTTLMinutes int`, `BufferMinutes int`, `UptimeThreshold float64`)
- `SourceMetrics` (`SourceID`, `Slot`, `Uptime float64`, `Active bool`, `State string`), `Metrics` (`ChannelID`, `Window`, `Uptime float64`, `Sources []SourceMetrics`, `Interruptions int`)
- `LogEntry` (`TS time.Time`, `SourceID`, `Process`, `Level`, `Message string`), `LogsResponse` (`Logs []LogEntry`, `Total int`)
- `APIError` (tipo error: `Code string`, `Message string`, `Fields map[string]string`); constructor desde el body `{"error":{...}}` y helpers `IsValidation(err) (APIError, bool)`, `IsNotFound(err)`, `IsConflict(err)` basados en `errors.As`.

## Pseudo código:
(no trivial solo en APIError)
```
decodeError(resp): json.Decode body → struct{Error APIError}
si decode falla: APIError{Code:"internal", Message:"respuesta inesperada de la API (status N)"}
```

## Criterios de aceptación:
- [ ] Un `Channel` con slots 2 y 4 vacíos deserializa desde JSON con `sources` conteniendo `null` en esas posiciones (test con el payload exacto de SPECS-001.5.1)
- [ ] Serializar `Channel` con slots nil produce `null` en esas posiciones (no omite el array)
- [ ] `APIError` implementa `error`; `IsValidation` devuelve true solo para `Code=="validation"` y expone `Fields`
- [ ] Los tags JSON coinciden con snake_case del contrato (`schedule_url`, `segment_seconds`, `uptime_threshold`, `source_id`)
