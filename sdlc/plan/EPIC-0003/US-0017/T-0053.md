# T-0053: Crear interfaz `APIClient` y base del cliente HTTP en `internal/apiclient/gateways.go` y `client.go`

## Descripción técnica:
Crear `internal/apiclient/gateways.go` [NUEVO] con la interfaz `APIClient` (la define el consumidor, SPECS-003.3):

```go
type APIClient interface {
    ListChannels(ctx context.Context) ([]Channel, error)
    GetChannel(ctx context.Context, id string) (Channel, error)
    CreateChannel(ctx context.Context, ch Channel) (Channel, error)
    UpdateChannel(ctx context.Context, id string, ch Channel) (Channel, error)
    DeleteChannel(ctx context.Context, id string) error
    GetConfig(ctx context.Context) (Config, error)
    PutConfig(ctx context.Context, cfg Config) (Config, error)
    GetMetrics(ctx context.Context, channelID, window string) (Metrics, error)
    GetLogs(ctx context.Context, channelID, level string, limit, offset int) (LogsResponse, error)
}
```

Crear `internal/apiclient/client.go` [NUEVO] con la struct `Client` (`baseURL string`, `http *http.Client`) y `NewClient(baseURL string, timeout time.Duration) Client` (retorna struct, no interfaz). Método privado `do(ctx, method, path string, query url.Values, body any, out any) error`: arma la request `{baseURL}/v1{path}`, propaga `ctx`, JSON encode/decode, y para status ≥ 400 decodifica a `APIError` (T-0052); errores de red/timeout se envuelven como `APIError{Code:"internal", Message:"API no disponible"}` preservando el error original con `%w` en un tipo `UnreachableError` distinguible. Tests contra `httptest.Server`.

## Pseudo código:
```
do(ctx, method, path, query, body, out):
    req = NewRequestWithContext(ctx, method, baseURL+"/v1"+path+"?"+query, jsonBody)
    resp = http.Do(req) // error → UnreachableError
    si resp.Status >= 400: retornar decodeError(resp)
    si out != nil: json.NewDecoder(resp.Body).Decode(out)
```

## Criterios de aceptación:
- [ ] Dado un `httptest.Server` que responde 400 con el body de error del contrato (con `fields`), `do` devuelve `APIError` con `Code="validation"` y los fields intactos
- [ ] Dado un servidor que no responde antes del timeout, `do` devuelve error distinguible como API inalcanzable (no `validation`)
- [ ] Dado un body de error malformado, `do` devuelve `APIError{Code:"internal"}` con el status en el mensaje (no panic ni error de decode crudo)
- [ ] La request saliente lleva `Content-Type: application/json` y path con prefijo `/v1`
