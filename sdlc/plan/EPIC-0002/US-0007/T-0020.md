# T-0020: Crear `Config` con Viper en `cmd/playlist/config.go`

## Descripción técnica:
Crear `cmd/playlist/config.go` [NUEVO] con la struct `Config` (`Port int`, `DatabaseURL string`, `StreamingDir string`, `DataDir string`, `LogsDir string`, `FFmpegPath string`, `FFprobePath string`, `YtDlpPath string`, `ChromiumPath string`, `ConfigPollInterval time.Duration`, `LogLevel string`, `ShutdownTimeout time.Duration`) y `LoadConfig() (Config, error)`. Viper con `AutomaticEnv`, prefijo `RODRITV_PLAYLIST`, `BindEnv` explícito y defaults según SPECS-002.6: `PORT=9290`, `STREAMING_DIR=/streaming`, `DATA_DIR=/data`, `LOGS_DIR=/logs`, `CONFIG_POLL_INTERVAL=15s`, `LOG_LEVEL=info`, `SHUTDOWN_TIMEOUT=15s`; `DATABASE_URL` requerida; paths de binarios con default `exec.LookPath` (autodetect en `$PATH`, error si no existe). `Validate()` falla si falta `DATABASE_URL`, puerto fuera de 1–65535, `LogLevel` inválido o `ConfigPollInterval < 5s`. `go mod tidy` para agregar `github.com/spf13/viper`.

## Pseudo código:
```
v = viper.New(); v.SetEnvPrefix("RODRITV_PLAYLIST"); v.AutomaticEnv()
set defaults; bind env por clave
cfg = Config{...}
para cada binario (ffmpeg, ffprobe, yt-dlp, chromium):
    si env vacío: cfg.<Path> = exec.LookPath(<nombre>) o error
si err := cfg.Validate(); err != nil: retornar err (fail fast)
```

## Criterios de aceptación:
- [ ] Dado `RODRITV_PLAYLIST_DATABASE_URL` ausente, `LoadConfig()` devuelve error de validación
- [ ] Sin variables seteadas, `Port` es 9290, `ConfigPollInterval` 15s y `ShutdownTimeout` 15s
- [ ] Dado un binario ausente de `$PATH` y sin override por env, `LoadConfig()` devuelve error indicando cuál falta
- [ ] Dado `RODRITV_PLAYLIST_FFMPEG_PATH=/usr/local/bin/ffmpeg`, se usa esa ruta sin LookPath
