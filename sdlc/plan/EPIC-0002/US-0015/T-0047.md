# T-0047: Crear handlers HLS, logos y registro de canal actual en `internal/streamserver/handlers.go`

## Descripción técnica:
Crear `internal/streamserver/handlers.go` [NUEVO] con `Handlers` (deps: `CachedChannelProvider` (T-0046), `streamingDir`, `dataDir`, callback `RecordRequest func(channelNumber int)` hacia `PowerScheduler` (T-0044)):

- `Playlist(w, r)`: `Content-Type: application/vnd.apple.mpegurl` (o `audio/x-mpegURL` — verificar compatibilidad SS-IPTV; elegir `application/vnd.apple.mpegurl`); host de la URL = `r.Host`. Render por request (T-0046).
- `ChannelPlaylist(w, r)`: `GET /channels/{n}/index.m3u8`. Registrar `RecordRequest(n)` **siempre** (pedir un canal apagado lo marca como actual y el Engine lo encenderá en ≤ 15 s). Si el archivo no existe aún (canal apagado), responder el `index.m3u8` del slate del canal si existe; si no hay nada, 404 con header `X-Reason: channel-off` (SS-IPTV reintenta solo). Servir con `http.ServeFile` + `Cache-Control: no-store`.
- `Segment(w, r)`: `GET /channels/{n}/seg-{seq}.ts` → `RecordRequest(n)` + `ServeFile` de `${STREAMING_DIR}/ch-<n>/seg-<seq>.ts`; `seq` validado numérico; 404 `X-Reason: segment-gone` si no existe (pudo salir de la ventana de retención).
- `Logo(w, r)`: `GET /logos/{filename}` desde `${DATA_DIR}/logos` con el mismo anti path-traversal de SPECS-001 (solo `[a-zA-Z0-9._-]`, extensión en `png|jpg|jpeg|webp|svg`); `Cache-Control: max-age=86400`.
- Path params con los patterns de ServeMux de Go 1.27 (`{n}`, `{seq}`, `{filename}`); validación de `{n}` entero positivo.

## Pseudo código:
```
ChannelPlaylist: n = atoi(r.PathValue("n")); si err: 404
    recordRequest(n)
    path = join(streamingDir, "ch-"+n, "index.m3u8")
    si no existe: path = slate index; si tampoco: 404 + X-Reason
    ServeFile
```

## Criterios de aceptación:
- [ ] httptest: `GET /playlist.m3u` devuelve la M3U con URLs absolutas basadas en `r.Host` y content-type correcto
- [ ] Pedir `index.m3u8` de canal apagado sin slate → 404 con `X-Reason: channel-off` y `RecordRequest(n)` invocado (callback fake)
- [ ] Pedir segmento existente → 200 y bytes; inexistente → 404 `X-Reason: segment-gone`; `seq` no numérico → 404
- [ ] `GET /logos/../etc/passwd` o nombre con caracteres inválidos → 404; logo válido → 200 con cache header
- [ ] Canal apagado con slate disponible → se sirve el index del slate (200)
