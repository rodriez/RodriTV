# T-0034: Crear sondeo de perfil con ffprobe en `internal/mixer/probe.go`

## Descripción técnica:
Crear `internal/mixer/probe.go` [NUEVO] con `Prober` (`NewProber(ffprobePath string)`) y `Probe(ctx, streamURL string) (Profile, error)`: ejecuta `ffprobe -v error -select_streams v:0 -show_entries stream=codec_name,width,height,r_frame_rate -of json <url>` más un segundo sondeo de audio (`a:0`, `codec_name,sample_rate,channels`), con timeout 20 s, y parsea el JSON a `Profile{VideoCodec string; Width, Height int; FPS float64; AudioCodec string; SampleRate, Channels int}`. Función `NeedsTranscode(p Profile) bool`: `true` salvo que sea exactamente H.264 + AAC con parámetros compatibles (decisión por source según SPECS-002.3.1.2: comparación contra el perfil de referencia del canal — primer perfil sondeado sano, H.264+AAC). El `SourceProcess` (T-0035) cachea la decisión mientras viva el proceso. Tests con binario fake de ffprobe que imprime JSON prefijado (H.264+AAC, HEVC, sin audio, JSON malformado, timeout).

## Pseudo código:
```
Probe: v = run(ffprobe ... v:0); a = run(ffprobe ... a:0)
profile = parse(v, a); si falta video: error "stream sin video"
NeedsTranscode(p): return !(p.VideoCodec=="h264" && p.AudioCodec=="aac")
```

## Criterios de aceptación:
- [ ] JSON H.264+AAC → `NeedsTranscode` false; HEVC+AAC o H.264+MP3 → true
- [ ] Stream sin stream de video → error descriptivo
- [ ] ffprobe con exit != 0 o JSON malformado → error con stderr y salida cruda
- [ ] Timeout 20 s cancela el proceso hijo
