# T-0035: Crear `SourceProcess` con ffmpeg supervisado y backoff en `internal/supervisor/sourceproc.go`

## Descripción técnica:
Crear `internal/supervisor/sourceproc.go` [NUEVO] con `SourceProcess` (1 goroutine supervisora + 1 subproceso ffmpeg). Constructor con dependencias inyectadas: `catalog.Source` y `catalog.Channel`, `extractor.Extractor`, `Prober` (T-0034), `ProcLogger` (T-0029), `ProcessLogWriter` (T-0028), `paths` (streamingDir), `ffmpegPath`, `clock` (interfaz `Clock` [NUEVA] con `Now()`/`Sleep` para determinismo). `Run(ctx) error`: loop de supervisión — resuelve URL (`Extractor.Resolve`), sondea perfil una vez por vida del proceso (`NeedsTranscode` decide la línea de ffmpeg), lanza ffmpeg:

```
remux:     ffmpeg -i <url> -c copy -f segment -segment_time <seg> -avoid_negative_ts make_zero -muxpreload 0 <dir>/seg-%05d.ts
transcode: idem con -c:v libx264 -preset veryfast -c:a aac
```

con stdout/stderr al `ProcLogger`; directorio `${STREAMING_DIR}/ch-<number>/src-<sourceID>/` (filepath.Join, `MkdirAll`). Al morir el proceso: registra en `process_logs` (comando completo, exit code, últimas 50 líneas de stderr vía `ProcLogger.Tail`) y reinicia con backoff exponencial 1 s → 2 → 4 → … máx. 60 s con jitter (±20%); tras 5 fallos consecutivos marca estado `degraded` (expuesto vía `State()` con mutex) y sigue reintentando en background. Un tramo con ≥ 2 segmentos producidos resetea el contador de fallos. Salud: `Healthy()` = proceso vivo Y último segmento nuevo hace < `2×segment_seconds + 2 s` (el supervisor la consulta en US-0013). Cancelación de ctx mata ffmpeg (`CommandContext`) y espera su salida.

## Pseudo código:
```
Run(ctx):
    failCount = 0; backoff = 1s
    loop:
        si ctx.Done: retornar nil
        url = extractor.Resolve(ctx, src) // cacheada; refresh en T-0036
        transcode = cacheado o prober.Probe(url) -> NeedsTranscode
        err = runFFmpeg(ctx, url, transcode) // bloquea hasta muerte
        reportLog(err); si produjo >=2 segmentos: failCount=0; backoff=1s; si no: failCount++
        si failCount >= 5: state = degraded
        clock.Sleep(jitter(backoff)); backoff = min(backoff*2, 60s)
```
