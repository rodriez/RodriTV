# T-0024: Definir tipos de dominio e interfaces gateway en `internal/catalog/gateways.go`

## Descripción técnica:
Crear `internal/catalog/gateways.go` [NUEVO] con los tipos del dominio de lectura y las interfaces que el motor consume (definidas por el consumidor, sin depender de pgx):

```go
type SourceType string // "m3u8" | "youtube" | "web"
type Source struct { ID uuid.UUID; Slot int (1-5); Type SourceType; URL string; Enabled bool }
type Channel struct { ID uuid.UUID; Number int; Name string; Logo string; Enabled bool; SegmentSeconds int; Sources [5]*Source }
type BehaviorConfig struct { Neighbors int; StartupChannels int; CurrentChannelTTL time.Duration; BufferMinutes int; UptimeThreshold float64 }
type ChannelReader interface { ListEnabled(ctx) ([]Channel, error) }
type ConfigReader interface { Load(ctx) (BehaviorConfig, error) }
```

`Channel.Sources` reproduce el array fijo de 5 slots del JSONB (slot i ↔ índice i-1); método `ActiveSources() []Source` (slots ocupados y `Enabled`, ordenados por slot) y `PrimarySource()` (slot ocupado más bajo, SPECS-001.5.2). Defaults de `BehaviorConfig` = semillas de SPECS-004.6 (neighbors 2, startup_channels 3, ttl 30 min, buffer 10 min, threshold 0.95). Incluir validación de invariantes al construir (`SegmentSeconds` 2–10, slots 1–5).

No aplica (tipos y validaciones simples).
