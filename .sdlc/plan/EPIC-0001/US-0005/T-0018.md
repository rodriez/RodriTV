# T-0018: Crear dominio `proclog`: repositorio, servicio, handler y ruta de logs

## Descripción técnica:
Crear `internal/proclog/entity.go` [NUEVO]: struct `LogEntry` (`TS`, `SourceID *uuid.UUID`, `Process`, `Level`, `Message string`) y `ListParams` (`Level` en `all|info|warn|error` default `all`, `Limit` 1–500 default 100, `Offset` ≥ 0 default 0) con validación. `gateways.go` [NUEVO]: interfaz `Repository` (`List(ctx, channelID, params) ([]LogEntry, int, error)` devolviendo entradas + total). `scripts/sqlc/proclog.sql` [NUEVO]: `ListProcessLogs` (ORDER BY ts DESC, LIMIT/OFFSET, filtro opcional por level) y `CountProcessLogs`. `postgres.go`, `service.go` (verifica existencia del canal vía `channel.Service.Get`), `handler.go` (parseo de query params). Registrar `"GET /v1/channels/{id}/logs"` y cablear en `main.go`.

## Criterios de aceptación:
- [ ] Respuesta según contrato SPECS-001.5.5 (`logs[]` + `total`), orden más reciente primero
- [ ] `limit=0` o `limit=501` → 400; `level=bogus` → 400
- [ ] Filtro `level=error` solo devuelve errores; `total` refleja el total filtrado
