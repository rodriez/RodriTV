# T-0006: Modelar entidades y errores de dominio en `internal/channel/entity.go` y `source.go`

## Descripción técnica:
Crear `internal/channel/entity.go` [NUEVO]: struct `Channel` (`ID uuid.UUID`, `Number int`, `Name string`, `Logo string`, `ScheduleURL string`, `Enabled bool`, `SegmentSeconds int`, `Sources [5]*Source`, `CreatedAt`, `UpdatedAt time.Time`) con métodos de invariantes `Validate() error` y constructor `NewChannel(...)`. Errores sentinelas/tipados: `ErrNotFound`, `ErrConflict`, `ErrValidation{Field, Msg string}` (con `Error()` y `Unwrap` apropiados). Crear `internal/channel/source.go` [NUEVO]: struct `Source` (`ID uuid.UUID`, `Slot int`, `URL string`, `Enabled bool`, `CreatedAt`, `UpdatedAt time.Time`) con `Validate()` (slot 1–5, URL http(s) parseable). Reglas: array de exactamente 5 posiciones; slots ocupados con `URL` válida y `Slot` igual a su posición 1-based; `Number` > 0; `Name` 1–100; `SegmentSeconds` 2–10 (default 5); `ScheduleURL` http(s) si presente.

## Criterios de aceptación:
- [ ] Canal válido pasa `Validate()`; nombre vacío o >100 → `ErrValidation{Field:"name"}`
- [ ] Source en slot 2 con `Slot=3` → error de validación; URL no-http(s) → error
- [ ] Array serializado siempre tiene 5 posiciones (slots vacíos como null) — test de marshalling
