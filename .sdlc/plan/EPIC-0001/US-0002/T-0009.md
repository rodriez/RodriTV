# T-0009: Implementar `Repository` PostgreSQL en `internal/channel/postgres.go`

## Descripción técnica:
Crear `internal/channel/postgres.go` [NUEVO]: struct `PostgresRepository` que implementa `Repository` usando las queries generadas por sqlc (T-0008) sobre `pgxpool`. Serializa/deserializa `Sources [5]*Source` a/desde JSONB con `encoding/json`. Asigna `ID` (uuid v4), `CreatedAt`/`UpdatedAt` con un reloj inyectable (`now func() time.Time`, default `time.Now().UTC()`). Mapea violación de unique de `number` (SQLSTATE 23505) a `ErrConflict` y "no rows" a `ErrNotFound`.

## Pseudo código:
```
Create(ctx, ch):
    ch.ID = uuid.New(); ch.CreatedAt = ch.UpdatedAt = now().UTC()
    row = q.CreateChannel(ctx, params{... sources: json.Marshal(ch.Sources)})
    si pgErr.Code == "23505": retornar ErrConflict{Field:"number"}
    retornar toDomain(row)
```

## Criterios de aceptación:
- [ ] Testcontainers (postgres:17-alpine) con migración real: Create/Get/List/Update/Delete funcionan y respetan orden por `number`
- [ ] Insertar `number` duplicado devuelve `ErrConflict`; `GetByID` inexistente devuelve `ErrNotFound`
- [ ] `sources` persiste y se lee como array JSONB de 5 posiciones
