# T-0001: Crear `Config` con Viper en `cmd/api/config.go`

## Descripción técnica:
Crear `cmd/api/config.go` [NUEVO] con la struct `Config` (`Port int`, `DatabaseURL string`, `DataDir string`, `LogLevel string`, `ShutdownTimeout time.Duration`) y la función `LoadConfig() (Config, error)`. Viper con `AutomaticEnv`, prefijo `RODRITV_API`, `BindEnv` explícito por clave y defaults: `PORT=9291`, `DATA_DIR=/data`, `LOG_LEVEL=info`, `SHUTDOWN_TIMEOUT=10s`. `DATABASE_URL` sin default. Método `Validate()` que falla si falta `DATABASE_URL`, si `Port` está fuera de 1–65535 o si `LogLevel` no es `debug|info|warn|error`. Agregar dependencias al `go.mod` (`github.com/spf13/viper`) vía `go mod tidy`.

## Pseudo código:
```
v = viper.New(); v.SetEnvPrefix("RODRITV_API"); v.AutomaticEnv()
set defaults; bind env por clave
cfg = Config{...}
si err := cfg.Validate(); err != nil: retornar err (fail fast)
```

## Criterios de aceptación:
- [x] Dado `RODRITV_API_DATABASE_URL` ausente, `LoadConfig()` devuelve error de validación
- [x] Sin variables seteadas, `Port` es 9291 y `ShutdownTimeout` 10s
- [x] Dado `RODRITV_API_PORT=1234`, `Config.Port == 1234`
