# T-0046: Crear render de la M3U maestra en `internal/streamserver/playlist.go`

## Descripción técnica:
Crear `internal/streamserver/playlist.go` [NUEVO] con `RenderPlaylist(channels []catalog.Channel, baseURL string) string` (función pura): `#EXTM3U` + una línea `#EXTINF:-1 tvg-chno="{number}" tvg-name="{name}" tvg-logo="{logoURL}",{name}` y la URL `http://<baseURL>/channels/{number}/index.m3u8` por canal habilitado, ordenados por `number`. `logoURL`: si el canal tiene logo, URL absoluta `<baseURL>/logos/{logo}`; si no, atributo vacío. Escapar comillas en nombres (reemplazo de `"`). El handler (T-0047) le pasa la lista cacheada 15 s (SPECS-002.4.13: render por request, lista de canales con TTL de caché de 15 s provista por un `ChannelProvider` con mutex — implementar el caché en `playlist.go` como `CachedChannelProvider` sobre `catalog.ChannelReader`).

## Pseudo código:
```
RenderPlaylist(channels, base):
    b = "#EXTM3U\n"
    para cada ch ordenado por number:
        b += `#EXTINF:-1 tvg-chno="N" tvg-name="name" tvg-logo="base/logos/logo",name` + "\n"
        b += "http://base/channels/N/index.m3u8\n"
CachedProvider.Get(ctx): si cache < 15s: devolver cache; si no: reader.ListEnabled + refrescar
```

## Criterios de aceptación:
- [ ] Dados 3 canales (uno deshabilitado, uno sin logo), la salida contiene solo los 2 habilitados, ordenados por número, con el formato exacto de tags de SPECS-002.5
- [ ] Nombre con comillas queda escapado; sin logo, `tvg-logo=""`
- [ ] El provider cacheado no consulta al reader más de 1 vez por ventana de 15 s (reader fake con contador + Clock fake)
