# T-0033: Implementar extractor web con chromedp en `internal/extractor/web.go`

## Descripción técnica:
Crear `internal/extractor/web.go` [NUEVO] con `WebExtractor` (implementa `Extractor`, T-0030) sobre `github.com/chromedp/chromedp` (vía `go mod tidy`). `Resolve`: lanza una instancia de Chromium headless por resolución (flags `--no-sandbox --headless=new --disable-gpu`, ejecutable de `BinariesConfig.ChromiumPath`), navega `src.URL`, instala un listener de red (`chromedp.ListenTarget` / network events) que captura el primer request cuya URL matchee `.m3u8` (ignorando query), y devuelve esa URL como `StreamURL`. Timeout global 45 s; si expira sin captura → error "no se detectó stream .m3u8 en la página". Pool: semáforo (`chan struct{}` capacidad 2) compartido en el extractor que acota a 2 browsers concurrentes; la tercera resolución espera. `RefreshInterval` = 10 min (los players regeneran URLs). Tests: extracción real contra un `httptest.Server` que sirve una página que pide un `.m3u8` fake (test de integración con tag `integration`, requiere chromium instalado; el resto — semáforo, timeout, errores — con contextos cancelables y browser fake donde sea posible).

## Pseudo código:
```
Resolve(ctx, src):
    sem <- {} ; defer <-sem  // pool máx 2
    ctx, cancel = WithTimeout(ctx, 45s)
    alloc = chromedp.NewExecAllocator(ctx, flags..., ExecPath(chromiumPath))
    var streamURL string
    chromedp.Run(alloc, ListenTarget(captura .m3u8 -> streamURL), Navigate(src.URL), esperar streamURL != "")
    si streamURL == "": error timeout/sin stream
    return StreamURL{URL: streamURL}
```

## Criterios de aceptación:
- [ ] (integration) Página de prueba que pide `stream.m3u8`: `Resolve` devuelve esa URL absoluta
- [ ] Página sin requests `.m3u8`: error a los 45 s (timeout inyectado más corto en test)
- [ ] Tres resoluciones concurrentes con pool 2: la tercera bloquea hasta que una termina (verificable con fakes del runner)
- [ ] `RefreshInterval` = 10 min
