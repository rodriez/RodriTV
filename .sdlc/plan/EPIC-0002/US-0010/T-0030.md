# T-0030: Crear interfaz `Extractor` y factory en `internal/extractor/extractor.go`

## Descripción técnica:
Crear `internal/extractor/extractor.go` [NUEVO] con la interfaz de SPECS-002.3.3:

```go
type StreamURL struct { URL string; Headers map[string]string } // headers por si el stream exige UA/Referer
type Extractor interface {
    Resolve(ctx context.Context, src catalog.Source) (StreamURL, error)
    RefreshInterval(src catalog.Source) time.Duration // 0 = no re-resolver
}
```

La factory es la única que construye extractores; `SourceProcess` (US-0011) depende de la interfaz, no de las implementaciones. Errores con `%w`.
