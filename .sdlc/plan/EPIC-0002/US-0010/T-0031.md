# T-0031: Implementar extractor m3u8 con detección de token en `internal/extractor/m3u8.go`

## Descripción técnica:
Crear `internal/extractor/m3u8.go` [NUEVO] con `M3U8Extractor` (implementa `Extractor`, T-0030). `Resolve`: devuelve la URL de la source tal cual; si la query contiene `token|signature|expires` (detección case-insensitive sobre los keys del query parseado con `net/url`), hace un `GET` a la URL origen configurada con `http.Client` con timeout 15 s para re-resolver (la respuesta puede ser la playlist con URL firmada nueva — se devuelve la URL definitiva) y `RefreshInterval` = 5 min; sin token, `RefreshInterval` = 0. URL inválida o no-http(s) → error de validación. Errores HTTP 4xx/5xx en la re-resolución se envuelven con `%w` incluyendo status.

## Pseudo código:
```
Resolve(ctx, src):
    u = url.Parse(src.URL); si esquema no http/https: error
    si tieneToken(u.Query()): return reGET(ctx, u)
    return StreamURL{URL: src.URL}
RefreshInterval(src): si tieneToken: 5min; si no: 0
```

## Criterios de aceptación:
- [ ] URL plana devuelve la misma URL y `RefreshInterval` 0
- [ ] URL con `?token=...` o `?expires=...&signature=...` se detecta como volátil y `RefreshInterval` = 5 min
- [ ] La re-resolución contra un `httptest.Server` que responde 200 devuelve la URL resuelta; ante 403 devuelve error con el status
- [ ] URL con esquema `file://` o string malformado devuelve error de validación
