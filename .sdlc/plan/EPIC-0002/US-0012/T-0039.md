# T-0039: Crear generación del slate de problemas técnicos en `internal/mixer/slate.go`

## Descripción técnica:
Crear `internal/mixer/slate.go` [NUEVO] con `SlateGenerator`: `Ensure(ctx, channel catalog.Channel) (dir string, error)` genera una vez por canal (cacheado en `${STREAMING_DIR}/slate/ch-<number>/`) un loop HLS del mismo perfil y duración de segmento del canal: `ffmpeg -f lavfi -i "color=c=0x1a1a2e:s=1280x720:r=30,drawtext=text='Problemas técnicos':fontcolor=white:fontsize=48:x=(w-text_w)/2:y=(h-text_h)/2" -f lavfi -i "anoisesrc=color=pink:amplitude=0.02" -c:v libx264 -preset veryfast -g <fps*seg> -c:a aac -f segment -segment_time <seg> ...`. Si drawtext no está disponible en el build de ffmpeg, fallback a color sólido sin texto (log warn). La generación es idempotente (si el dir existe con segmentos válidos, se reutiliza). Integración con `ChannelMixer` (T-0038): el slate se expone como una "source virtual" (`SetActiveSource(slateID)`), de modo que el failover a slate reutiliza exactamente la misma maquinaria de publicación, DISCONTINUITY y numeración monótona (SPECS-002.3.1.5).

## Pseudo código:
```
Ensure(ctx, ch):
    dir = join(streamingDir, "slate", "ch-<n>")
    si dir tiene >= 3 segmentos válidos: return dir
    run ffmpeg lavfi -> dir/seg-%05d.ts durante ~30s de material en loop finito
    return dir
```

## Criterios de aceptación:
- [ ] `Ensure` genera segmentos TS reproducibles (ffprobe confirma H.264+AAC) de duración = `SegmentSeconds` del canal
- [ ] Segunda llamada con el cache presente no re-ejecuta ffmpeg
- [ ] El mixer conmutando a slate mantiene MEDIA-SEQUENCE/PDT monótonos y emite DISCONTINUITY (test conjunto con T-0038)
- [ ] Binario ffmpeg fake sin drawtext → fallback a color sólido + warn, sin error
