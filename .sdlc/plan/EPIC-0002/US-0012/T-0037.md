# T-0037: Spike PoC: mezcla continua con 2 sources reales (gate RFC riesgo n.º 1)

## Descripción técnica:
Spike descartable (no se mergea al diseño final; vive como test de integración con tag `integration` o script en `build/poc/` [NUEVO]) para validar la premisa central antes de construir el `ChannelMixer`: ingerir 2 sources HLS reales del set del RFC con ffmpeg `-c copy` a segmentos de 5 s, y componer a mano (script Go) una `index.m3u8` única con MEDIA-SEQUENCE y PROGRAM-DATE-TIME monótonos que conmute de source A a B a mitad, verificando que (1) ffplay/ffmpeg -i o un reproductor HLS reproduce la playlist resultante sin error de continuidad y (2) el `EXT-X-DISCONTINUITY` en el límite es tolerado. Entregable en código: el script/test que reproduce el escenario de forma repetible + documentación del resultado (conclusión en el comentario del test: viable / ajustes necesarios). Si la PoC falla → detener US-0012 y reabrir SPECS-002 (la decisión 2 queda en duda).

## Pseudo código:
```
srcA = ffmpeg -i <urlA> -c copy -f segment -segment_time 5 poc/a/seg-%05d.ts (correr ~30 s)
srcB = idem <urlB> en poc/b/
componer index.m3u8: segs de a (seq 0..k), EXT-X-DISCONTINUITY, segs de b (seq k+1..)
verificar: ffprobe/ffmpeg -i index.m3u8 -c copy -f null - sin errores de PTS/continuidad
```

## Criterios de aceptación:
- [ ] La playlist compuesta con conmutación A→B se procesa sin errores fatales de continuidad en ffmpeg/ffprobe
- [ ] La misma prueba con sources de distinto frame rate (25 vs 30 fps si el set lo permite) documenta el comportamiento
- [ ] Conclusión registrada: la mezcla por playlist es viable para el set de sources, o lista de ajustes necesarios para T-0038

## Definición de finalizado (DoD):
- [ ] Script/test repetible commiteado (tag `integration`)
- [ ] Conclusión del spike documentada y compartida con el usuario (gate antes de T-0038)
- [ ] Lint/type-check sin errores (`go vet` y `gofmt` limpios)
- [ ] Deployable de forma independiente (no forma parte del binario)

## Proyecto / módulo: rodritv-playlist / `build/poc/` o `internal/mixer/` (test integration)
## Tamaño: S
## Depende de: T-0034 (probe); requiere ffmpeg instalado y URLs reales (dependencia externa de la EPIC)
