# T-0041: Crear ventana deslizante de uptime y sampler en `internal/supervisor/uptime.go`

## Descripción técnica:
Crear `internal/supervisor/uptime.go` [NUEVO] con `UptimeTracker` por canal: mantiene una ventana deslizante de 1 hora por source (y una global del canal = unión: hubo salida de alguna source o del slate), con muestras booleanas cada 5 s ("produjo segmento esperado") alimentadas por el `ChannelSupervisor` desde `SourceProcess.Healthy()` y la actividad del mixer. API: `Record(sourceID *uuid.UUID, ok bool)` (nil = global), `Uptime(sourceID *uuid.UUID, window time.Duration) float64` (ratio ok/total en la sub-ventana pedida), y `RunSampler(ctx, writer telemetry.UptimeWriter)` [goroutine]: cada 30 s persiste una muestra agregada en `uptime_samples` por source activa + una global (ok_count/total_count del último minuto de muestras de 5 s; total esperado 6). `Clock` inyectable para determinismo; thread-safe (mutex). Las ventanas se implementan como ring buffer de (ts, ok) con descarte de muestras > 1 h.

## Pseudo código:
```
Record(src, ok): ring[src].append(clock.Now(), ok); podar ts < now-1h
Uptime(src, window): filtrar ts >= now-window; si total==0: 0; else ok/total
RunSampler: ticker 30s: para cada source: writer.InsertSample({channel, src, ok, total}); global idem (source NULL)
```

## Criterios de aceptación:
- [ ] Con Clock fake: 10 min de muestras ok=true y 2 fallos → `Uptime(src, 15min)` = 8/10 dentro del rango esperado
- [ ] Las muestras de más de 1 h se descartan y no afectan el ratio
- [ ] El sampler persiste cada 30 s una fila por source + una global (source NULL) con el conteo correcto (writer fake)
- [ ] Sin muestras en la ventana, `Uptime` devuelve 0 (no NaN)
