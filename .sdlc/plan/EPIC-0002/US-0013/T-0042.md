# T-0042: Crear `ChannelSupervisor` con failover lógico en `internal/supervisor/supervisor.go`

## Descripción técnica:
Crear `internal/supervisor/supervisor.go` [NUEVO] con `ChannelSupervisor` (1 goroutine por canal encendido, `errgroup` interno con ctx propio cancelable). Constructor: `catalog.Channel`, factories/deps para crear `SourceProcess` (T-0035) y `ChannelMixer` (T-0038), `SlateGenerator` (T-0039), `UptimeTracker` (T-0041), `ProcessLogWriter`. `Run(ctx) error`: levanta mixer + slate ensure + sampler de uptime + un `SourceProcess` por cada source que deba correr (inicialmente todas las `ActiveSources()`; la regla del 95% de T-0043 puede apagar/prender backups). Loop de supervisión cada 5 s: evalúa `Healthy()` de cada `SourceProcess` por orden de slot; la primera sana se vuelve activa (`mixer.SetActiveSource(srcID)`); si ninguna está sana → `mixer.SetActiveSource(slateID)` + evento warn en `process_logs`; al recuperarse una source de mejor slot, se vuelve a ella. Cada tick registra `Record(src, healthy)` y `Record(nil, haySalida)` en el tracker. Cancelar el ctx apaga sources y mixer y espera (`WaitGroup`) a que mueran todos los ffmpeg y goroutines — nunca goroutines huérfanas. Estado expuesto: `Status()` (source activa, por source: healthy/degraded) para `/healthz` y futuros diagnósticos.

## Pseudo código:
```
Run(ctx):
    eg, ctx = errgroup.WithContext(ctx)
    eg.Go(mixer.Run); eg.Go(sampler.Run); slate.Ensure(ctx, ch)
    para cada source a correr: eg.Go(sp.Run)
    loop ticker 5s:
        activa = primera source con Healthy() por orden de slot
        si activa == nil: mixer.SetActiveSource(slateID); log warn si cambió
        si no: mixer.SetActiveSource(activa.ID) si cambió
        registrar muestras en tracker
    <-ctx.Done(): cancelar hijos; eg.Wait()
```

## Criterios de aceptación:
- [ ] Con SourceProcess y mixer fake: la activa es la de menor slot sana; al degradarse, conmuta a la siguiente sin intervención
- [ ] Con todas las sources insanas: el mixer recibe slate y se registra warn; al sanar la principal, vuelve a ella
- [ ] Las muestras de uptime (ok/fallo por source y global) se registran cada 5 s en el tracker
- [ ] Cancelar el ctx mata todos los hijos y `Run` retorna sin goroutines vivas (`go test -race`)
