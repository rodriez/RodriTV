# T-0026: Implementar gateways PostgreSQL en `internal/catalog/postgres.go`

## Descripción técnica:
Crear `internal/catalog/postgres.go` [NUEVO] con `PostgresCatalog` que implementa `ChannelReader` y `ConfigReader` (T-0024) usando las queries generadas por sqlc (T-0025) sobre el `pgxpool.Pool` de `internal/platform` (T-0021). `ListEnabled`: mapea filas a `Channel` deserializando `sources` JSONB al array `[5]*Source` (slot = índice+1). `Load`: lee todas las claves de `config`, aplica tipado por clave (`neighbors` int, `current_channel_ttl_minutes` int→Duration, `uptime_threshold` float64, etc.) y completa con defaults ante claves ausentes; error solo ante valores inválidos (no parseables), con la clave en el mensaje. Errores envueltos con `%w`.

## Pseudo código:
```
ListEnabled: rows = q.ListEnabledChannels(ctx); para cada row: json.Unmarshal(row.Sources, &[5]*Source); construir Channel
Load: kv = map de GetConfig; cfg = defaults(); para cada clave conocida: parse según tipo o error "config key X: %w"
```

## Criterios de aceptación:
- [ ] Integración testcontainers con la migración `000001_init` aplicada: dado 3 canales (2 habilitados) con sources en slots 1 y 3, `ListEnabled` devuelve los 2 habilitados ordenados por número con sus sources mapeadas al slot correcto
- [ ] Dado JSONB de sources con slot nulo, el canal carga con ese slot en nil
- [ ] Dado tabla `config` vacía, `Load` devuelve los defaults de SPECS-004.6
- [ ] Dado valor no parseable (p.ej. `neighbors = "abc"`), `Load` devuelve error que nombra la clave
