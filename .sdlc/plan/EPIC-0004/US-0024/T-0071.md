# T-0071: Crear `scripts/install.sh` idempotente

## Descripción técnica:
Crear `scripts/install.sh` [NUEVO] (bash, `set -euo pipefail`, ejecutable). Pasos según SPECS-004.3:

## Pseudo código:
```
#!/usr/bin/env bash
set -euo pipefail
RODRITV_HOME="$HOME/.rodritv"

# 1. Dependencias del host: falla con mensaje claro si falta `docker` o `docker compose` (v2).
#    Advertencia (no fatal) si id -u != 1000.
# 2. mkdir -p "$RODRITV_HOME"/{db,data,streaming,logs} "$RODRITV_HOME/data/logos"
#    (ownership del usuario actual por construcción; no tocar permisos si ya existen)
# 3. cp deployments/docker-compose.yml "$RODRITV_HOME/docker-compose.yml"   # siempre actualiza
#    si no existe "$RODRITV_HOME/.env":
#        generar desde .env.example con POSTGRES_PASSWORD=$(openssl rand -hex 24)
#    si existe: no tocarla (idempotencia de credenciales)
# 4. docker compose -f "$RODRITV_HOME/docker-compose.yml" --env-file "$RODRITV_HOME/.env" pull || true
#    docker compose ... up -d
# 5. imprimir URLs del panel (http://<host>:9292) y playlist (http://<host>:9290)
```

## Criterios de aceptación:
- [ ] Dado un host sin `docker` o sin compose v2, el script falla antes de tocar nada con mensaje claro
- [ ] Primera ejecución: crea el árbol de directorios, genera `.env` con contraseña aleatoria y levanta el stack
- [ ] Segunda ejecución (idempotencia): no regenera la contraseña, no borra datos de `~/.rodritv/db`, actualiza la copia del compose y deja el stack corriendo
- [ ] Dado un usuario con uid ≠ 1000, advierte pero continúa
- [ ] `shellcheck scripts/install.sh` limpio

## Definición de finalizado (DoD):
- [ ] `shellcheck` sin errores ni warnings
- [ ] Test manual de doble ejecución verificado (idempotencia)
- [ ] Tests existentes sin romper
- [ ] Código mergeado tras code review
- [ ] Deployable de forma independiente (sin pasos manuales fuera del pipeline)
