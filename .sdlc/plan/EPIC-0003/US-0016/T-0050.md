# T-0050: Crear `http.Server` con middleware y ciclo de vida en `cmd/web/server.go`

## Descripción técnica:
Crear `cmd/web/server.go` [NUEVO] con `NewServer(cfg Config, handler http.Handler, logger *slog.Logger) *http.Server` (timeouts: `ReadHeaderTimeout=5s`, `ReadTimeout=15s`, `WriteTimeout=30s`, `IdleTimeout=60s`) y `Run(ctx context.Context, srv *http.Server, shutdownTimeout time.Duration) error` (arranque en goroutine, escucha `signal.NotifyContext` en main; `Shutdown` con `context.WithTimeout`). Middleware por composición de `http.Handler` en el mismo archivo: `withLogging(logger)` (campos `request_id`, `method`, `path`, `status`, `duration_ms` via wrapper de `ResponseWriter` que captura status; `request_id` = UUID v4 generado por request, header `X-Request-ID`) y `withRecover()` (recover de panic → 500 + log con stack). `go mod tidy` para `github.com/google/uuid`.

## Pseudo código:
```
Run(ctx, srv, timeout):
    go srv.ListenAndServe() // error != ErrServerClosed → canal de error
    select: err del canal | <-ctx.Done()
    ctxShutdown, cancel = WithTimeout(timeout); defer cancel()
    retornar srv.Shutdown(ctxShutdown)
withLogging: next.ServeHTTP(statusCapturingWriter, r); logger.Info(...campos...)
withRecover: defer recover() → log.Error(stack) + http.Error(500)
```

## Criterios de aceptación:
- [ ] Dado un handler que responde 200, el log incluye `method`, `path`, `status=200`, `duration_ms` y un `request_id` no vacío
- [ ] Dado un handler que hace panic, la respuesta es 500 y el proceso sigue sirviendo requests siguientes
- [ ] Dado `SIGINT` durante una request en curso, `Run` espera su fin hasta `ShutdownTimeout` y devuelve nil
- [ ] Cada respuesta incluye header `X-Request-ID` igual al `request_id` logueado

## Definición de finalizado (DoD):
- [ ] Tests unitarios de la lógica agregada/modificada en verde
- [ ] Tests existentes sin romper
- [ ] Lint/type-check sin errores (`go vet` y `gofmt` limpios)
- [ ] Código mergeado tras code review
- [ ] Deployable de forma independiente (sin pasos manuales fuera del pipeline)
