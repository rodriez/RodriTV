# T-0056: Crear paquete `web/` con embed.FS, htmx vendored y handler `/static/*`

## Descripción técnica:
Crear `web/web.go` [NUEVO] (paquete `web`, raíz del repo según project-layout) con:
```go
//go:embed templates static
var FS embed.FS

func Static() http.Handler // http.FileServer(http.FS(sub FS "static")) con Cache-Control: max-age=86400
func Templates() fs.FS     // sub FS "templates"
```
Descargar y commitear `web/static/vendor/htmx.min.js` [NUEVO] (release v2.x pinneada, archivo único minificado; registrar la versión exacta en un comentario de `web/web.go`). Crear placeholders reales mínimos `web/static/css/panel.css` y `web/static/js/panel.js` [NUEVO] (se completan en T-0058) para que el embed no falle por directorios vacíos. Registrar en `cmd/web/routes.go` la ruta `GET /static/` → `http.StripPrefix("/static/", web.Static())`. Middleware de cache: wrapper que setea `Cache-Control: max-age=86400` en respuestas de `/static/*`.

## Pseudo código:
```
Static():
    sub, _ = fs.Sub(FS, "static")
    retornar cacheHeader(http.FileServer(http.FS(sub)))
```

## Criterios de aceptación:
- [ ] `GET /static/vendor/htmx.min.js` responde 200 con el JS de htmx y header `Cache-Control: max-age=86400`
- [ ] `GET /static/../templates/layout.html` o cualquier path fuera de `static/` responde 404/400 (no sirve templates)
- [ ] El binario compila y funciona sin acceso a disco externo (assets embebidos)
- [ ] La versión exacta de htmx queda documentada en `web/web.go`
