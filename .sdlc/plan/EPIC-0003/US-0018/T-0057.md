# T-0057: Crear cargador de templates y FuncMap en `internal/panel/render.go`

## Descripción técnica:
Crear `internal/panel/render.go` [NUEVO] (paquete `panel`) con:
- `type Renderer struct { t *template.Template }` y `NewRenderer(templatesFS fs.FS) (Renderer, error)` que parsea de una vez `layout.html`, `pages/*.html` y `partials/*.html` con `template.New("").Funcs(funcMap).ParseFS(...)`; error de parseo → se propaga y `main` hace exit 1 (fail fast).
- `funcMap` con los helpers de SPECS-003.3: `formatUptime(f float64) string` (0.987 → `"98.7 %"`, 2 decimales, guion para valores < 0), `formatTime(t time.Time) string` (formato `02/01 15:04:05` en hora local), `stateClass(state string) string` (`running`→`st-on`, `standby`→`st-standby`, `failed`/`error`→`st-off`, default `st-unknown`).
- `Render(w http.ResponseWriter, name string, data any) error` que ejecuta el template nombrado; en error hace log + `http.Error` (el handler no repite esta lógica).
- `internal/panel/render_test.go` [NUEVO]: test que parsea **todos** los templates embebidos reales (detecta errores de sintaxis en CI) + tests de cada helper.

## Pseudo código:
```
NewRenderer(fsys):
    t, err = template.New("").Funcs(funcMap).ParseFS(fsys,
        "layout.html", "pages/*.html", "partials/*.html")
    si err: retornar err
    retornar Renderer{t}
```

## Criterios de aceptación:
- [ ] Dado cualquier error de sintaxis en un template (test con FS en memoria), `NewRenderer` devuelve error
- [ ] El test de parseo corre contra el `embed.FS` real de `web/` y pasa
- [ ] `formatUptime(0.987)` → `"98.70 %"`; `stateClass("running")` → `"st-on"`
- [ ] `Render` escribe el fragmento nombrado en el `ResponseWriter` con `Content-Type: text/html; charset=utf-8`
