# T-0065: Crear fragmentos de métricas y logs con polling htmx

## Descripción técnica:
Agregar a `internal/panel/fragments.go` [NUEVO]:
- `MetricsFragment`: `GET /frag/channels/{id}/metrics?window=24h` → `api.GetMetrics` → `partials/metrics_card.html` [NUEVO]: tarjeta con uptime (`formatUptime`), interrupciones, tabla de sources (slot, uptime, `stateClass`, activa/standby). El contenedor lleva `hx-get` a la misma ruta con `hx-trigger="every 5s" hx-swap="outerHTML"` (auto-polling, SPECS-003.4.3).
- `LogsFragment`: `GET /frag/channels/{id}/logs?level=all` → `api.GetLogs(ctx, id, level, 100, 0)` → `partials/logs.html` [NUEVO]: líneas de log (más recientes primero, `formatTime`, nivel coloreado, proceso, mensaje) + selector de nivel (`all|info|warn|error`) que cambia el `hx-get`; contenedor con `hx-trigger="every 3s"`.
Errores: red/5xx → el fragmento devuelve el banner "API no disponible, reintentando" (el polling reintenta solo); 404 → aviso sin polling (eliminar `hx-trigger` en esa respuesta). Integrar ambos fragmentos en el bottom panel de `partials/channel_detail.html` (T-0060): reemplazar el placeholder por los contenedores de métricas y logs del canal seleccionado. Registrar rutas en `cmd/web/routes.go`. Tests con `APIClient` mockeado: verifican atributos `hx-trigger`, parámetros propagados y ramas de error.

## Pseudo código:
```
MetricsFragment:
    m, err = api.GetMetrics(ctx, id, window o "24h")
    si IsNotFound: render metrics_card{SinDatos} (sin hx-trigger); return
    si err red: render banner con polling intacto; return
    render metrics_card{M: m, Poll: true}
```

## Criterios de aceptación:
- [ ] El fragmento de métricas incluye `hx-trigger="every 5s"` y el de logs `every 3s` apuntando a su propia ruta
- [ ] `?window=7d` y `?level=error` se propagan a `GetMetrics`/`GetLogs` (verificado en el mock)
- [ ] Dado error de red, el fragmento muestra "API no disponible, reintentando" y mantiene el polling
- [ ] Dado 404, el fragmento muestra el aviso y NO incluye `hx-trigger`
- [ ] El bottom panel del detalle de canal (`/frag/channels/{id}`) renderiza métricas y logs del canal seleccionado
- [ ] Validación manual (cierre de EPIC): alta de canal y navegación del layout desde smartphone Android
